For each photo: tap the top-left corner of the obstacle, then its bottom-right corner, and type how far away it was in metres. Use the same camera you will walk with (phone or ESP32-CAM), with the whole obstacle in view. The app learns its name and its size at each distance.

Use the same Wi-Fi as the ESP32-CAM. The address is shown in the Arduino Serial Monitor. If the page is on https and the picture stays blank, allow “Insecure content” for this site in the browser settings.

When something in your path can't be named by the app, a small picture of just that obstacle is sent to Claude, which names it. Needs internet and uses a little of your API credit. The key stays only in this browser. Never put it in the GitHub files.

To read labels, hold the item 20 to 30 cm from the camera, steady, in good light. For the ESP32-CAM, set a larger picture size (SVGA or higher) in the CameraWebServer sketch, or small print will not be readable.

Fast: quick, knows 80 common objects. Wide: slower (a few seconds per scan), recognises many more things such as doors, stairs, poles and shoes.
